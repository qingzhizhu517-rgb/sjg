# 双风格切换治理方案：一页一貌，消除重复实现

> 问题：主题开关(real/inkwash)对全部页面生效，很多页面为此维护了两套布局/文案/样式，效果重复且鸡肋。
> 思路：**每页固定一种风貌**；主题开关只做两件事——①全局明暗/强调色/背景材质(token 级) ②首页保留完整的双轨叙事(唯一卖点)。
> 现状盘点(grep 实测 86 处双风格引用)与决策如下。

## 决策表

| 页面/组件 | 现状重复点 | 决策风貌 | 动作 |
|---|---|---|---|
| 首页 MapView/RiverHero | real=24节气画卷+3D沙盘 / inkwash=开场视频+水墨长卷 | **保留双轨**(首页特色, 全站唯一完整双体验) | 不动 |
| 诗词 PoemDetail | 两套布局(real 横排 body / inkwash 竖排诗笺) | **恒水墨竖排诗笺** | 删 real 分支, 统一走 ink-poem-scroll, 配色随 token |
| 诗人 PoetDetail | 两套模板(展馆档案卡 / 人物小传卷) | **人物小传卷**(卷轴式最有辨识度) | 合并为单模板, 删 pd--real 分支与双份样式 |
| 景点 SpotDetail | 单一版式(已重构), 仅 seal/色调随主题 | **单一版式** | 已达标, 仅保留 token 变化 |
| 时间轴 Timeline | 页级 themeClass + InkTimeline 水墨长卷 | **恒水墨长卷** | 删 themeClass 分支, 固定水墨 |
| 名士 PoetList / DynastyRail | anime-layout 条件样式(卡片细线化等) | **纸面风貌(统一)** | 删除条件分支, 样式并入基类; 双文案合并 |
| 五类列表(Festival/FoodOpera/Literature) | anime-layout 条件样式 + 双标题文案 | **纸面风貌(统一)** | 同上 |
| 文化长廊 / 每城文化页 / CulturalGallery | anime-layout 条件样式 + 双标题文案 | **纸面风貌(统一)** | 同上 |
| 详情 CulturalDetail / RegionSpots / CraftWorkshop / FestivalDetail(退役文件) | anime-layout 条件样式 | **纸面风貌(统一)** | 删条件分支 |

## 实施批次

| 批 | 内容 | 风险 |
|---|---|---|
| A | 列表/文化/城市/图谱页: 删除 `anime-layout` 条件分支与双文案, 统一纸面风貌(细线+印章+留白样式直接并入基类) | 低, 纯删减 |
| B | PoemDetail 恒水墨竖排(删 real 分支) | 中, 需验双主题下排版 |
| C | PoetDetail 合并为单一小传卷(删双模板) | 中, 需验信息不丢 |
| D | Timeline 固定水墨; ThemeSwitcher 文案改为「实景叙事/水墨叙事」仅首页生效提示; 全局 token 明暗切换保留 | 低 |

## 效果预期

- 每页只有一套布局代码, 维护量减半, 不再出现"两套效果重复"
- 主题开关 = 全局质感(米白纸面/暖黄纸面 + 强调色)切换 + 首页双轨, 不再让每个页面都"演两遍"
- 页面风貌各具辨识: 首页=实景/水墨双轨 · 诗词=竖排诗笺 · 诗人=小传卷 · 时间轴=水墨长卷 · 文化/列表=日式纸面
