## 1. 整体优化升级，数据库表设计等各种信息

### 1.1 数据库表结构优化
- **现有表分析**：审查 `dynasty`, `poet`, `scenic_spot`, `poem`, `event`, `poem_event`, `user`, `poet_relation`, `cultural_item`, `festival_detail` 表。
- **字段优化**：
  - 为所有表添加 `deleted` 软删除标志（逻辑删除）。
  - 统一时间字段：`created_at`, `updated_at`, `deleted_at`。
  - 为 `poem` 表添加 `word_count`（字数）、`line_count`（行数）字段，便于统计分析。
  - 为 `poet` 表添加 `achievement`（主要成就）、`influence`（影响力）字段。
  - 为 `scenic_spot` 表添加 `opening_hours`（开放时间）、`ticket_info`（门票信息）、`visit_tips`（游览建议）字段。
- **新增表**：
  - `cultural_item_detail`：文化条目通用详情表（1:1 关联 `cultural_item`），存储 `origin`（起源）、`process`（工艺流程）、`significance`（文化意义）、`inheritors`（传承人）等。
  - `ai_poem_analysis`：AI 诗词分析结果表，存储 `poem_id`, `analysis_type`（情感/意象/手法等），`content`（分析内容），`model_used`（使用的 AI 模型）。
  - `user_collection`：用户收藏表，支持收藏诗词、诗人、景点、文化条目。
  - `user_note`：用户笔记表，支持对诗词的批注和感悟。
- **索引优化**：
  - 为高频查询字段添加索引：`poem.poet_id`, `poem.dynasty_id`, `poem.spot_id`, `cultural_item.category`, `cultural_item.region`。
  - 为 `poet_relation` 表添加复合索引 `(poet_a_id, poet_b_id)`。

### 1.2 数据迁移与种子数据
- 编写迁移脚本（遵循 `V7__*.sql` 命名规范）。
- 为 `cultural_item` 表准备民俗节庆、非遗工艺、民间文学、饮食戏曲的种子数据。
- 为 `cultural_item_detail` 表准备对应的详情数据。

### 1.3 API 接口优化
- **现有接口增强**：
  - `GET /api/public/poems/{id}`：返回 AI 分析结果（`ai_poem_analysis`）。
  - `GET /api/public/poets/{id}`：返回诗人关系图谱数据（`poet_relation`）。
  - `GET /api/public/cultural-items`：支持按 `category` 和 `region` 筛选。
- **新增接口**：
  - `GET /api/public/cultural-items/{id}/detail`：获取文化条目详情（含扩展表数据）。
  - `POST /api/public/ai/analyze-poem`：调用 AI 分析诗词（情感、意象、手法、翻译等）。
  - `POST /api/public/ai/compose-poem`：AI 写诗（主题、风格、字数等参数）。
  - `GET /api/public/poet-relations`：获取诗人关系图谱数据（用于可视化）。
  - `GET /api/public/statistics`：平台统计数据（诗人数量、诗词数量、景点数量等）。
  - `POST /api/public/user/collections`：用户收藏（需登录）。
  - `GET /api/public/user/collections`：获取用户收藏列表（需登录）。

## 4. AI 针对具体诗词页面进行分析

### 4.1 AI 分析功能
- **分析维度**：
  1. **情感分析**：诗词表达的情感（豪放、婉约、悲壮、闲适等）。
  2. **意象分析**：关键意象（黄河、泰山、明月、杨柳等）及其象征意义。
  3. **手法分析**：修辞手法（比喻、拟人、夸张、对偶等）。
  4. **翻译赏析**：白话文翻译 + 赏析。
  5. **创作背景**：历史背景、诗人生平关联。
  6. **相关诗词**：相似主题或风格的诗词推荐。
- **交互设计**：
  - 诗词详情页下方设置“AI 分析”标签页。
  - 分析结果以卡片式分块展示，支持展开/收起。
  - 支持用户选择分析维度（情感、意象、手法等）。
  - 分析结果支持收藏、分享。

### 4.2 技术实现
- 后端调用 DeepSeek API（或其他 LLM），使用特定 prompt 生成分析。
- 前端使用流式展示（SSE），逐段显示分析结果。
- 分析结果缓存到 `ai_poem_analysis` 表，避免重复调用。

  - 预生成常用汉字的笔画动画数据（SVG 路径）。
  - 使用 Canvas 或 SVG 实现书写动画。
  - 支持自定义书写速度、笔触粗细。

### 5.2 技术实现
