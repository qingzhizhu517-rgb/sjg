# AI 对照阅读设计

## 授权与定位

用户将 AI 展示形态、UI 与切入点交给代理并要求进行优化；此前确认视觉尽量出图。本轮采用“从两篇作品寻找山水的不同写法”，以独立对照阅读工作区承载原文、可核验线索与个人思考。方案由代理自主确定并实施，保留暖纸水墨风格。

## 首版范围

- 新增懒加载 `/reading`。参数 `poem`、`compare` 为正整数诗词 ID，`region` 与 `spot` 用于选材，`returnTo` 只接受站内地址；`preview=inkwash` 保留现有显式样本规则。
- 阅读页由紧凑山水页头、选材栏、双篇原文、AI 比较线索和个人笔记组成。桌面两篇并排，手机纵向；不使用整张效果图替代可点击 UI。
- 支持意象、视角、情绪、语言四个比较方向。首次进入只加载原文与状态，不自动调用模型。
- 原文按去除空行后的行号排列；可点选原句加入本机证据清单。AI 请求以服务端读取的两篇完整原文为依据，使用 `[A:1]`、`[B:2]` 标记行引用。AI 引用只有材料与行号确实存在时才显示可点击原文定位；不得把模型说法标为事实。
- 个人思考本机保存，以材料 ID 对作为草稿键，保存失败给可见提示，不阻断阅读或 Markdown 导出。导出包含材料标题、原文、实际来源、选句、个人判断，AI 文字明确标注“AI解读”及状态，途中/停止结果标为未完成。
- 首版不扩展任意散文、教师任务 JSON 编辑、公开课程目录或全站聚合搜索；已有绑定任务反馈和学习提交继续保持原契约。

## 数据与生成边界

正式数据调用 `GET /api/public/poems` 分页选材与 `GET /api/public/poems/{id}` 原文及来源，不把 API 失败改成样本。无已发布材料时说明状态，提供显式“查看对读样本”入口。

样本复用 atlasPreview 的作品；零 API/模型调用。可展示明确标注的“导读示例，非实时AI”，不宣称其关联经审核。

新增 `GET /api/public/ai/status`：Result 包裹 `{generationConfigured:boolean,reason:'configured'|'not_configured'}`。只判断配置，不探测模型、不暴露配置值；UI 文案为“可尝试生成”或“生成尚未配置”。状态请求失败说明无法确认，允许主动重试。原文、已发布赏析与笔记不因生成不可用隐藏。

新增 `POST /api/public/poems/compare`，SSE，请求为：

```json
{"poemIds":[1,2],"focus":"imagery","mode":"compare","answer":""}
```

服务端校验恰好两项、正数、不重复、focus 与 mode 白名单；feedback 模式必须有非空且不超3000字的 answer。每篇存在、published 且原文非空；超过20000字符的单篇明确拒绝，不静默截断。只使用服务端原文/来源，忽略客户端伪造原文、来源、history。允许两篇同一 sourceId。未通过校验不调用 LLM，不回退第三篇检索资料。

SSE 命名事件：`evidence` 包含 `{materials:[{id,label,title,lines:[{number,text}],sources}],auditId?}`；`delta` 包含 `{delta}`；`error` 包含 `{error}`；`done` 包含 `{done:true}`。材料载荷可补作者/朝代，缺失保持为空。沿用已有 IP 解析、RateLimitService、LLM 与审计；比较和反馈结果不写入赏析表、不改变发布状态。

比较提示要求区分原文、推断、来源缺失，引用对应行；反馈提示只指出证据覆盖与推理遗漏，不代写结论。用户答案与原文均作为数据区域，不能覆盖系统指令。

## 状态与交互

加载、无数据、材料不存在、来源未登记、未配置、等待、流式生成、完成、停止、错误分别呈现。生成期间禁止重复点击，可停止；切换材料、方向、模式和离开页面取消旧流，晚到响应不可污染新状态。提前 EOF 且没有 done 不作完成；保留部分结果但标明中断。

Markdown 消毒；引用控件仅匹配现有材料/有效行号。不直接信任生成的链接。两个来源面板不能重复 DOM heading ID，可使用单一合并来源区域并保留材料归属。

全站导览/研学分区新增“AI对照阅读”，学习首页、诗词列表、诗词详情、景点页、济南等城市体验提供入口并保留城市、来源页和样本参数。阅读页关闭全局悬浮助手以避免手机遮挡；其他页面小文欢迎语与实际生成配置一致，保留原问答能力。

## 视觉资产

内置 image_gen 生成一张横向工作区效果图（仅设计参考）及一张无字“山水与书卷”横幅（运行时素材）。暖纸、水墨青绿、朱印色一致；横幅压缩WebP <250KB，整体新增媒体<3MB。记录提示词、生成方式、尺寸和SHA256，不用旧积分生成链路。

## 验收

后端验证 published 边界、原文完整性、来源与同书材料、伪造字段、限流、审计与状态字段；新增注入需真实 Spring 容器装配测试。前端验证选材请求竞态、流停止/尾事件/提前关闭、样本零网络、草稿损坏/存储失败、导出、引用定位与参数保留。

规格审查通过后执行独立质量审查；前后端全量与仓库契约门禁通过。1440px/390px真实浏览器检查，使用样本检查完整布局、真实云 API 检查空态与配置状态。发布至已有 Railway 后端与原 Sites 展示站，保持原访问范围；其他前端不变。主干与 auto/improve 同步，部署状态记录实际应用代码基线，不以配置状态代替真实模型质量验收。
