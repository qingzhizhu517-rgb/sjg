# 东昌葫芦工坊：实施与验收记录

日期：2026-10-11。推荐方案 B 的基础写实 3D 与制作闭环已实施；用户追加的视频到制作路径一起交付。

## 实施范围

- 默认“匠人实录”：人民周刊网／人民视频原站 HTTPS 视频点击后在页面播放，保留标题、日期、来源原页及加载失败入口；央视《农广天地》提供明确的原页观看入口。视频文件不下载、不随构建分发。
- 视频预览组件和资料结构可复用于其他工艺；新增来源须核验 HTTPS 地址与媒体域名。视频与 3D 舞台按模式挂载，离页释放资源。
- 连续曲面、细微不对称、干蒂、内壁、底痕、绳结；自然壳色、颜色／粗糙度／动态法线纹理、环境光、接触阴影与侧光。无需缺失的 GLB 即可进入 3D。
- 三种数字坯形、梅枝／莲花／游鱼三组原创构图，位置、比例和方向可调整；跟刻／自由练习、刻刀深度和容错、敷色与擦色、撤销重做。
- 实际笔迹决定进度和成品；观摩完成不伪造作品。保存最近六件到本地、恢复编辑、删除确认及 PNG 导出；损坏存储或容量失败有反馈。
- 原五工序导览、连续播放、前后切换、知识、探索记录导出、返回列表与预览参数保留。原 GLB 舞台的加载就绪、动画取消、位姿隔离和资源释放一并修正。

## 真实浏览器结果

本地 Chromium／Ego 浏览器，访问当前工作树 `localhost:5175/crafts/workshop`，没有依赖后端样本替代制作状态。

| 项目 | 结果与证据 |
| --- | --- |

| 旋转与复位 | 通过方向键累计转动一周，检查背面与回到正面；复位恢复默认机位；放大、缩小与侧光已操作 |
| 三维描刻 | 实际指针输入留下 UV 刻线；撤销与重做改变笔迹数，画稿不自动变成刻槽 |
| 敷色与擦色 | 桌面练习由 0% 到敷色 78%、擦净 78%，完成门槛成立；保存“春枝 · 验收作品”，重新进入后从作品集恢复同一组 3 笔操作 |
| 成品导出 | 通过下载事件取得 `春枝 · 验收作品-东昌葫芦.png`，下载失败值为空；检查 PNG 含真实刻线和器物，无参考稿 |
| 手机触摸 | 390px 模拟手机，长腰／莲花自由练习实际产生 11 点刻线；双指缩放及 touchCancel 后笔迹数仍为 1，没有把手势残痕提交 |

| 响应式 | 390／768／1440px 布局核查，无横向内容溢出。小屏单栏与四个等宽模式入口；宽屏舞台填满容器。长腰坯形按模型及干蒂实际高度适配机位，三形全部顶点投影回归测试通过 |

| 五工序与减少动态 | 连续播放实际到第五步并停止，制作笔迹仍为空；减少动态偏好下直接到末步且不启用连续播放 |
| 渲染暂停 | 静止舞台 `pendingFrame=false`，离屏 `paused=true`；真实隐藏标签页会取消未结束笔迹并停止连续播放 |

手机测试是浏览器触摸与屏幕模拟，并非实体手机硬件性能结论。桌面最后一帧 CPU 观测约 1–2ms、手机模拟约 0.4–8.8ms，首次／纹理更新曾超过 40ms；这些不等同 GPU 帧率，不宣称达到 60／30fps。全部场景资源预算（包含暂时隐藏道具）约手机 29,590、桌面 61,574 三角面；实际提交渲染的面数随工序变化。桌面纹理 1536px、手机 1024px，DPR 上限分别为 2／1.5。

自动化浏览器的分段 mouse 操作曾在动作间触发 document.hidden，取消了未完成笔迹。通过取消堆栈定位，并用连续 CDP 原生指针事件验证完整刻／敷／擦操作；保留真实隐藏时取消草稿的正常生命周期规则，未放宽该规则迎合工具。

## 边界
