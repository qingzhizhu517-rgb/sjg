# 东昌葫芦雕刻：文化调研与 3D 工坊升级方案

日期：2026-10-11。状态：用户已确认推荐方案 B；基础写实 3D、制作闭环与视频入口已实施，验收记录另附。

配套资料：[来源与证据目录](2026-10-11-dongchang-hulu-research-evidence.md)。目录按政策名录、官方传承人及专题、媒体工艺报道、技术文档分层，登记具体出处、证据价值与可信度，并逐项映射到设计依据。

## 1. 目标与边界

将现有五工序导览升级为兼具文化准确性、器物质感与动手乐趣的数字工坊。
保留 `/crafts/workshop`、五个工序入口、前后切换、连续播放、知识讲解、非遗列表返回及预览参数。
保持全站水墨纸面界面，舞台内采用写实葫芦与工艺工具。

## 2. 调研结论与设计依据

### 2.1 可核实的文化背景

东昌葫芦雕刻为 2008 年第二批国家级非物质文化遗产代表性项目，类别为传统美术，申报地区为山东省聊城市。
工艺以东昌府区堂邑镇为中心传播，与大运河商贸及当地蓄养蝈蝈的生活习俗有关。
吉祥纹样、人物故事、山水、花鸟虫鱼等题材构成其文化表达；师徒传承是重要的传承方式。
这些背景分别见中国非遗网项目记录与专题介绍，不把传说中的创始人或未经核验的传承年数写成确定史实。
国家级名录身份由证据目录 E01/E02 支撑；地域文化由 E02/E04 支撑；人物身份与技法参考见 E03。

来源：

- [中国非遗网：葫芦雕刻（东昌葫芦雕刻）](https://www.ihchina.cn/project_details/14147.html)
- [中国非遗网：雕福塑瑞专题](https://www.ihchina.cn/niansu/html/diaoFuSuRui_dongChangHuLuDiaoKe.html)

### 2.2 造型与工艺

亚腰葫芦为上小下大、中央束腰的天然形态；另有扁圆、长柄等形制。
设计应根据真实器物调整上下腹比例、腰部曲率、干蒂与自然不对称，避免将两个球体简单叠加。
去皮后的外壳具有自然土黄色；去皮处理不等于露出白色内瓤。

央广网采访记录了选料、雕刻、着色的基本流程：雕刻后敷色，再擦净外表，让凹槽留色以突出纹样。
因此保留现有五个教学章节，但把末步扩为“着色与成品”，默认表现敷色、擦色与刻槽显纹。
彩绘、烙画和镂雕可以作为不同技法分支，不将某种颜料、固定红绿黄配色或某种雕法描述为全部东昌作品的必经规范。
现有“霜降后”“晾晒月余”等精确时间须有对应工艺来源才能保留，不将游戏中的快速演示当作真实加工时长。
形制、土黄色外表和凹槽留色对应 E05；三道概括工序拆成五个教学章节属于产品设计，不作为传统工序数量的证据。

来源：

- [央广网：东昌葫芦雕刻](https://country.cnr.cn/xtxq/201312/t20131226_514502938.shtml)
- [中国非遗网：代表性传承人李玉成](https://www.ihchina.cn/ccr_detail/2927.html)

### 2.3 转化为设计规则

| 调研特点 | 视觉和玩法转化 |
| --- | --- |
| 天然形体，因形构图 | 根据不同葫芦形制提供腹部、肩部与腰部的构图区域；切换坯形后重新检验纹样布局 |
| 自然黄褐色外壳 | 微斑点、细纹和柔和反光，维持植物外壳质感 |
| 细腻刻线与凹槽留色 | 雕刻深度与染色遮罩共用同一笔迹数据，完成擦色后真正显出所刻图案 |
| 吉祥和叙事题材 | 纹样卡展示题材与来源；首期采用原创梅枝、莲花、游鱼构图，复杂戏曲人物后续扩展 |
| 不同技法各有特点 | 主线先做好阴刻与擦色；烙画和镂雕分阶段扩展，各自说明工艺差异 |

## 3. 改造前的问题（首次检查）

依据改造前工作树代码与本地浏览器实测，未检查远程生产服务器资产；这些问题已在本次实施中修正：

1. `HULU_PROCESS.model` 指向 `/media/crafts/dongchang-hulu.glb`，但当前工作树没有该文件，浏览器使用 `HuluIllustration` 二维 SVG。五步可切换，但并没有实际的 3D 器物。
2. 降级到 SVG 后仍显示“自由赏玩”提示；二维模式没有相应的旋转功能。
3. `CraftStage` 在 `scene.init()` 后、`scene.load()` 前发送 `ready`，父页面提前进入首道工序。接入模型时需要先加载、取得真实部件清单，再通知工序就绪。
4. `useGlbScene` 有 Three.js、OrbitControls 和射线拾取基础，但目前没有环境反射、接触阴影、微表面纹理或雕刻笔迹系统。
5. `CraftWorkshop` 的悬停处理把整个部件放大，再恢复为单位缩放，可能破坏导入模型的原始比例，表现也容易跳动。
6. `useCraftProcess` 的淡入实际为缩放出现；工序动画未统一保存与取消，位姿基准 Map 在模块级共享。反复切步与多个实例需要单独验证。
7. 现有“玩法”主要是切步与观看动画，缺少由玩家操作生成作品的反馈循环。不能把跳到末步当作完成动手制作。
8. 工艺文案及资产指南偏向白色壳体、彩绘和浮雕，需要按调研区分基础雕刻流程与扩展技法。

相关代码：`CraftWorkshop.vue`、`CraftStage.vue`、`HuluIllustration.vue`、`useGlbScene.js`、`useCraftProcess.js`、`content/crafts/dongchang-hulu.js`、`public/media/crafts/GLB-GENERATION-GUIDE.md`。

## 4. 方案选择

| 方案 | 范围与取舍 |
| --- | --- |
| A：插画精修 | 优化 SVG、文案和切步体验，投入小；不能满足真正立体呈现与雕刻互动 |
| B：参数化写实 3D 工坊（推荐） | 用连续曲面制作可靠的葫芦本体，PBR 材质、工序导览、表面描刻与擦色；保留后续 GLB 接口，质量与实现成本较平衡 |
| C：完整工艺模拟器 | 实时实体切削、任意透雕、复杂工具物理与开放式工作台；开发和移动端性能成本高，首期收益不足 |

推荐 B。参数化建模用于稳定的基础形体，复杂镂雕及叙事作品可以后续接入经过检查的 GLB，不依赖缺失文件或未经后处理的自动生成模型。

## 5. 视觉与立体呈现

### 5.1 模型

- 连续曲面塑造上下腹和束腰，保证轮廓、法线与腰部连接自然；自然不对称为轻微变化，避免破坏可用 UV。
- 首期三种亚腰形制：匀称、长腰、丰腹；明确其为数字形制选项。扁圆、长柄作为后续资产扩展，不用拉伸现有网格冒充。
- 增加干蒂、底部生长痕、内外壳区分和有限厚度；雕刻工具的刃口、刀柄与金属连接分件制作。
- 细微刻痕采用动态高度和法线信息；近景浅槽可适当使用几何深度。真正镂空必须有孔洞、内壁与孔缘，不能只用黑贴图冒充。

### 5.2 材质

- 葫芦使用非金属 PBR 材质，组合颜色、粗糙度及微表面法线；天然斑点保持克制。
- 干坯为米黄至黄褐色；避免瓷白、塑料高光与黄金金属感。
- 刻槽色泽、深浅与玩家笔迹关联；擦色阶段清除外表覆盖色，保留沟槽中的染色。
- 木柄、金属刃口、陶瓷颜料碟与绳结各自使用材质，不共享一种光泽。
- 2048px 纹理为桌面上限参考，手机优先 1024px；分辨率以近景观感与实测显存为依据。

### 5.3 光照与舞台

- 使用柔和主光、弱补光、轮廓光与经过预过滤的环境光，突出腹部体积和腰部曲率。
- 用接触阴影让器物落在台面上；提供侧光查看刻痕的赏鉴机位。
- 统一输出色彩与曝光；纸面背景克制，避免大幅装饰山水抢夺器物主体。
- 不对整个场景增加强泛光或高饱和滤镜，刻槽、轮廓和材质成为视觉重点。

Three.js 技术依据：[材质说明](https://threejs.org/manual/pages/materials.html)、[PMREMGenerator](https://threejs.org/docs/pages/PMREMGenerator.html)。法线贴图改变光照表现而不改变真实轮廓，因此镂雕与显著孔缘仍须几何表达。

### 5.4 观看与操作

- 观摩模式的每道工序都有稳定默认机位，可选择暂停、旋转、放大与复位；继续播放时恢复工序机位。
- 用局部轮廓或热点提示取代整体器物缩放；支持点击知识点与独立文字知识列表。
- 操作与旋转分别使用明确模式，避免同一拖动同时刻线与旋转。
- 手机提供旋转/刻刀切换、工具档位和清晰的复位按钮；不依赖悬停或设备压力感应。
- 限制缩放与俯仰范围，防止穿入壳体或丢失器物；两指缩放、按钮缩放均可使用。
- 触摸的 `touch-action` 只在操作舞台内约束，不锁定整页滚动。

## 6. 保留核心玩法并增加制作循环

页面提供四个明确入口：“匠人实录”“观摩工序”“动手制作”“作品赏鉴”。按用户追加要求默认实录；原有五步及连续播放保留，不被制作门槛阻挡。人民周刊网视频通过原站链接在页内预览，央视专题保留原页观看入口。视频点击后加载，离开实录时停止并释放播放资源；实录入口不启动 WebGL。

动手制作主循环：选坯 → 布纹 → 描刻 → 敷色与擦色 → 检视并保存。
游戏中的快进处理明确标为演示，不暗示真实葫芦能即时晾干。

| 环节 | 玩家操作 | 即时反馈与趣味 |
| --- | --- | --- |
| 选坯 | 从三种形制选择一只，旋转检查腹部与腰部 | 不同形体对应不同构图空间，给出选料提示 |
| 布纹 | 从三组原创纹样选择构图，调整位置、大小及方向 | 弧面预览和腰部拥挤提示，避免纹样拉伸或越界 |
| 描刻 | 跟随参考线描刻，选择浅/中/深档位 | 刀尖落在命中表面，刻线随笔迹出现；支持撤销和局部重试 |
| 敷色与擦色 | 选择有限墨色/赭色方案，拖动敷色并擦去浮色 | 刻槽逐渐显纹，未刻区域不会自动出现成品图案 |
| 赏鉴 | 旋转、近看、切换侧光，命名作品 | 查看原坯与成品对比，保存到本地作品集、重新编辑或导出图片 |

制作模式首期包含“跟刻入门”和“自由练习”。参考线允许辅助描刻，容错可调；评分关注线条覆盖、偏离程度及重复过深操作，给出原因与改善提示。
评分是数字体验反馈，不称为专业工艺鉴定或非遗技艺认证。自由创作不强制审美评分。
题材知识卡在需要选择时出现，避免操作过程中被长篇文字遮挡。

观察进度与制作进度分别保存；切换观摩章节不能伪造制作完成。回看前序不清除作品，重新选坯或清空作品须明确提示。

后续扩展为烙画练习、有限预制镂雕图样与戏曲叙事纹样。它们有独立的工具、表现方式与介绍，不将任意颜色变化统一称为雕刻。

## 7. 与现有项目的衔接

- `CraftWorkshop` 负责编排模式、当前工序、作品参数和工具面板，不直接混入底层网格代码。
- `CraftStage` 管理 Canvas、加载、降级与生命周期；模型完成加载和部件验证之后才发送就绪。
- `useGlbScene` 保留通用渲染、相机、拾取接口，补充容器 ResizeObserver、渲染质量档位与资源释放；工坊专属材质和形体在独立模块中构建。
- 新增独立制作状态层，保存坯形、纹样、工具档位、笔迹、着色和模式；与原有工序状态机分开。
- 射线命中获得表面 UV，将连续笔迹映射到共享雕刻遮罩；处理 UV 接缝和大幅跳点，不连接跨越背面的两次命中。
- 拾取同时检查部件及祖先的可见性，隐藏工序的部件不能拦截点击或刻线。
- 工序状态机改为实例级位姿快照，切步先取消前序动画并恢复基准；真淡入和终态显隐分开处理。
- 更换模型或坯形时释放旧几何、材质、纹理、控制器与订阅；页面离开后无遗留动画或渲染循环。
- 作品首期仅存本地版本化参数和笔迹，提供清空与导出。若将来新增公开作品社区，另行设计审核与存储，不绕过现有治理。
- 文案、列表缩略图、降级插画和资产生成指南同步更新，保持形制、纹样与工序一致。

UV 拾取依据：[Three.js Raycaster](https://threejs.org/docs/pages/Raycaster.html)。

## 8. 性能、降级与验收

### 8.1 目标

- 桌面交互目标 60fps，中档手机目标 30fps；这些是待验证目标，不是已达到的成绩。
- 模型按桌面/手机质量档位控制，首期整场景约 3 万至 8 万三角面作为预算参考；纹理、阴影和像素比均可降低。
- 不仅用 CPU 核数或内存字段阻止进入 3D，而是依据 WebGL 初始化和运行表现降级。
- 不在每个指针事件中重建整只模型；笔迹采样与纹理更新合并到渲染帧。
- 离屏、后台标签页及静止场景停止无效渲染；减少动态偏好下提供静态机位和直接终态。
- 2D 降级显示真实能力说明，保留五步导览、平面纹样练习与知识讲解，隐藏不支持的 3D 旋转提示。

### 8.2 必验项目

1. 无外部 GLB 的初次进入即可展示可旋转的三维本体；标准浏览器不再仅落到二维插画。
2. 五工序、连续播放、前后切步、知识说明、返回列表和预览参数继续可用。
3. 连续快速切步、重复进入、离页返回后无部件残留、缩放漂移或动画相互覆盖。
4. 绕器物一周查看：曲面连续、腰部无接缝、纹样无悬浮闪烁、材质无过曝；干蒂、刻槽及阴影可辨。
5. 用户描刻的位置、深度和擦色结果与最终作品一致；撤销、重做、本地恢复和导出一致。
6. 区分点击与拖动，覆盖笔迹跨 UV 接缝、未命中表面、旋转后继续雕刻及多触摸场景。
7. 390 / 768 / 1440px 排版、触摸操作、WebGL 失败降级和减少动态偏好均验证。
8. 新增真实场景就绪、状态恢复、笔迹和评分规则测试；浏览器截图与实际 WebGL 操作验收不可由源码字符串测试替代。
9. 运行展示端单测、生产构建与仓库质量关卡；性能在指定浏览器和设备记录帧时间、加载时间与资源占用。

## 9. 落地顺序与预期效果

第一阶段：修正工艺文案和 3D 就绪链路，完成参数化本体、材质、灯光、旋转/缩放/复位，以及正确降级。先审查五步近景和各机位效果。

第二阶段：加入选坯、布纹、表面描刻、敷色擦色、撤销与制作进度，保留原导览模式；完成本地作品集与图片导出。

第三阶段：增加适配资源的烙画、镂雕及叙事纹样，扩展教学挑战。仅在前两阶段视觉和交互验收通过后进行。

预期从“点击步骤观看插画”升级为“观察工艺、亲手制作、检视保存作品”的闭环：器物能近看、能转动，刻线和色泽有依据，玩家的选择与操作能留下可辨的作品差异。
趣味性和学习效果需通过实际试玩观察完成率、重试情况、不同作品数量及工艺理解反馈验证，不预先承诺留存提升比例。

实施结果与实测边界见 [验收记录](2026-10-11-dongchang-hulu-acceptance.md)。
