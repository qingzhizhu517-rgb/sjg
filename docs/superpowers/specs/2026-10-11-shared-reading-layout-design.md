# 展示端统一阅读排版

## 目标与范围

按用户提供的景点详情截图，优化中间内容区域的可读性，并让规则可复用于全站。
范围为 display-v2 展示端普通阅读页面及共享组件：图册、城市、景点、名士、诗词、四类文化、时间线、研学、对照阅读与创作。
管理端和 1920×1080 数据大屏各有独立应用布局，不混用展示端容器；沉浸式沙盘的画布与滚动场景保留原有布局。

## 排版维度

| 维度 | 统一规则 | 实现位置 |
| --- | --- | --- |
| 栅格与布局 | 普通页面最大外宽 1360px；卡片按可用空间自动排布；两栏阅读在 960px 以下折为单栏 | variables.css、layout.css 的 folio-page / folio-grid / folio-split |
| 间距 | 4px 基础尺度；页边距 20–48px；栅格间隔 24–40px；章节间隔 32–56px；面板内边距 20–32px | 布局 token |
| 对齐 | 页面、导航、页脚采用同一页边距；取消城市册页、名士正文重复叠加的外边距；标题和操作区按阅读起点对齐 | folio-page、PageHeading 与局部页面布局 |
| 字体与层级 | 保留本地宋体/楷体字体栈；页标题 32–48px，章节标题 22–28px，卡片标题 20px，阅读正文 16px，辅助文字 12–14px | folio-section-title、folio-prose、共享标题 |

## 使用约定

- 普通路由页的根节点使用 `folio-page`，页面专属 class 保留用于插画及独特构图。
- 列表使用 `folio-grid`；通过 `--folio-card-min` 配置最小卡片宽度，默认 280px。
- 两栏内容使用 `folio-split`；通过 `--folio-columns` 配置比例；子列始终允许收缩。
- 章节使用 `folio-section` / `folio-section-title`；长段落使用 `folio-prose`。
- 布局 token 只在 variables.css 中定义；layout.css 只实现布局和阅读规则。
- 新页面复用这些规则，不复制固定页宽和断点。装饰、图片构图与 Canvas 样式仍由原组件负责。

## 景点详情

首区按约 1:2 显示景观介绍与诗词情感面板，二者有明确间隔，插画进入正常文档流，不再跨列或依赖固定顶部偏移。
代表诗词单独成节，文案、人物图与入口分别排布；一首作品保持有限行宽，多首作品由栅格排布。
情感概览独立成节，统计与方法说明分栏，窄屏纵向排列。
空内容、无标签与长描述沿用真实数据状态，不补造曲线或诗词。

## 功能边界与验收

不修改 API、公开发布门禁、分页数量、路由规则、预览数据、AI 调用、图表赋分、作品展开逻辑。
保留键盘标签页操作、朝代筛选、来源链接、页面返回与预览 query。
验证 display-v2 全量现有单测和生产构建，并在浏览器检查 390 / 768 / 1440px 的代表页面。
视觉验收包含单首、多首、空关联诗词、窄屏图文排版与来源长文本；预览样本仅用于验收，不作为 API 降级。

- 现有 214 项单元测试通过；生产构建与 `git diff --check` 通过。

- 共享规则优先级调整后，对七类页面再次检查三种宽度，正文为 16px，章节标题为 22–28px，未发现横向溢出。

- 浏览器验证朝代筛选、地图标签页、方向键切换及焦点、诗词关键词搜索；预览 query 与筛选 query 保留。
- 本轮未连接真实后端数据库；视觉验收使用显式设计预览及本地测试接口。
