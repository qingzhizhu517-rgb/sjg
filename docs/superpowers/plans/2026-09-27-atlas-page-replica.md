# 水墨册页页面复刻实施记录

**目标：** 将用户四张参考图的统一淡彩水墨风落实为可操作网页，覆盖首页、城市、诗人与景点，并统一全站公共样式。

**架构：** 保留 Vue、路由和公开 API。参考图裁切为独立插画，页面文字和交互使用 HTML/Vue/ECharts；不使用整页截图覆盖。预览参数 `?preview=inkwash` 明确启用设计样本，真实页面接口失败不自动使用假数据。

**授权：** 用户已阅读可行性方向，并明确要求不论采用何种方法尝试复刻，直接进入实施。素材来源为本次用户提供的参考图及项目既有资源；本次未调用生图模型。

## 边界

预览样本中的景点关联与情感标签只为版式和交互演示，并非经过审核的分析数据。页面必须标注设计预览；正常路由继续真实公开接口和来源展示。

裁切素材受参考图原始分辨率限制；本次保留可替换的独立素材路径，后续可直接换入高分辨率母版。

## 完成结果与验证

覆盖首页、城市册页、人物详情、景点详情四类核心页面，另接通名士名单与诗词详情预览。其他业务页沿用原结构并继承公共视觉，不作为本次四张参考图的逐页复刻范围。

- 首页：青绿黄河主画、书法题字、六景卡片、特色体验、九城入口。六景分别打开 101–106 对应详情。
- 城市：左侧城市档案与竖幅山景、右侧六景和独立竖排题款；其他城市预览保留城市资料，未准备景点样本时明确显示空态。
- 人物：杜甫大幅立绘、两列独立题诗、资料、生平与作品；支持李清照、王士禛、老舍的独立样本。手机保留人物全幅并为题诗留出位置。
- 景点：大明湖湖景、按朝代筛选的标签曲线、诗词卡片和标签分布；支持展开全部诗词、人物列表、坐标示意。缺失或未知标签不补情感分；作者接口失败不阻断诗词内容。
- 原三维地图移至 `/river-sandbox`，`RiverSandbox.vue` 与改造前 `MapView.vue` 逐字节一致。
- 17 项透明 WebP 总计 1,642,934 字节；来源及高清替换说明见 `display-v2/public/media/inkwash/atlas/README.md`。
