# 展示站水墨风格与交互重设计

**目标：** 在已认可的淡彩水墨视觉上，重排展示站的导航、按钮层级、筛选与返回流程，覆盖全部公开路由。

**授权：** 用户明确要求整体改造并授权自行决定合理布局。本轮直接设计和实现，不重复请求设计批准。不使用 arkcli。

**架构：** 保留 Vue 3、公开 API、来源与审核边界。以共享导航配置、页头组件和操作样式建立一致性；各业务页面保留独立数据逻辑。设计样本只允许由 `preview=inkwash` 显式启用。

## 设计决策

采用「分区导航 + 页内工作区」，而非继续堆叠原有按钮或只替换颜色。首层为首页、山河探索、诗文名士、齐鲁文化、研学创作；分区中提供对应列表、地图、时间线和创作入口。全站导览收纳九城与完整导航。手机提供可键盘操作的抽屉。

每页最多突出一个主要操作：朱砂主按钮、细墨边次按钮、文字辅助链接。操作命名使用具体动词。搜索、筛选、结果数量和重置在同一工作区；筛选同步网址并支持返回恢复。错误不替换页头与导航，空结果能直接清除筛选。阅读页提供确定的上级与相关内容入口，减少依赖浏览器历史。步骤页把上一步、下一步、完成/导出放到一致区域。

视觉沿用宣纸、淡青绿山水和朱砂。控件最小点击高度 44px，文字 14px 左右，状态以描边、文字和形状同时表达。表单有标签、可见焦点与禁用状态；移动端筛选换行或使用选择框，避免挤成细小标签。

## 共享接口

- `components/ui/PageHeading.vue`：`eyebrow`、`title`、`description`、`image`、`backTo`、`backLabel` 属性；默认及 `actions` 插槽。页面可直接使用本组件，也可保留独特主画。
- `styles/interactions.css`：`.folio-page`、`.folio-button`（`--primary` / `--secondary` / `--quiet`）、`.folio-actions`、`.folio-toolbar`、`.folio-field`、`.folio-input`、`.folio-select`、`.folio-filter`、`.folio-tabs`、`.folio-result-bar`、`.folio-empty-actions`、`.folio-panel`。业务模块保留必要 scoped 布局。
- `config/siteNavigation.js`：分区定义、活动分区判定与链接。所有设计预览链接复用 `atlasLink`，不静默混用真实和样本数据。

## 边界

本轮针对与参考图对应的公众展示站 `display-v2`。已有数据大屏保留入口。后端、管理端业务及数据不修改。现有插画可复用，不假称重新生成高清原画；不进行提交、发布或外部消息发送。

## 验收

每条公开路由可从导航或相关内容到达；列表错误时仍可导航与调整条件。控件及卡片无需依靠悬停理解。手机无横向整页溢出。筛选不会产生重复请求或旧请求覆盖新结果。阅读和步骤操作使用真实按钮/链接。来源、未审核数据与真实加载失败的边界保留。
