## 2. 视觉方向与使用流程

采用“宣纸底色、矿物青绿山体、金褐河水、暖色斜照、轻薄远雾”的立体山河图志。真实感来自地形起伏、河岸、物体尺度和接触阴影；宏观视图保留文化图册气质，近景再呈现材质与地标细节。

建议流程：全省鸟瞰 → 悬停/选择城市 → 平滑靠近 → 侧栏阅读与进入城市；用户主动进入布置模式后，才出现素材库、变换工具与撤销入口。地形编辑位于局部城市场景，避免要求手机同时编辑整省高精度地表。

- 常驻工具：放大、缩小、俯视、复位、标签、画质、动态效果；紧凑屏幕折叠次要控件。
- 探索模式：优先文化浏览；节点、标签和侧栏共享同一选择状态。
- 布置模式：拖入建筑/植被，落地吸附，实时调整位置、朝向、尺度。
- 地形模式：抬升、压低、平滑、定高；显示笔刷范围和影响强度。
- 演示天气明确标注“场景效果”；不将其表述为实时气象。

## 3. 渲染质量、地形与资产

### 3.1 连续地形与真实河道

1. 将行政边界从地形表面分离；规则高度网格或分块网格承载地形，边界作为叠加线层。处理 Polygon 洞与 MultiPolygon；用面积/屏幕误差简化，避免以顶点数直接删除岛屿。
2. 地形、河道、城市、建筑统一使用经纬度投影与高程采样接口。登记坐标系、水平比例、垂直夸张倍率；渲染坐标与原始高程分开。
3. 有授权 DEM 时接入真实高程；无 DEM 时保留明确标注的程序化示意地形。记录底图、河线、DEM 的来源、许可、版本与处理方式，不虚构地理精度。
4. 河道由有来源的中心线按弧长重采样，生成可变宽度的左右岸 ribbon 网格。水位与地形联合约束，河岸局部下切；地形编辑不得让水面穿山或无缘由上坡。
5. 水面以流向 UV、低幅度法线扰动、岸线色差表现流动；金色流光保留为讲解叠加层。省域河宽如果为可见性放大，应标注比例示意。

### 3.2 材质、光影和后处理

1. 明确 sRGB 输出；颜色贴图使用 sRGB，法线/粗糙度/高度数据不套用颜色贴图转换。选择一种 tone mapping（先比较 ACES 与 AgX），统一曝光；自定义 Shader 与后处理只执行一次正确的输出转换。
2. 使用一盏投影方向光塑造山体，环境贴图经 PMREM 预滤波补充材质反射；避免用过强环境光抹平轮廓。环境资产先从低分辨率开始。
3. 阴影视锥贴合有效场景/当前局部区域，按档位使用 1024² 或 2048²，实机校准 bias/normalBias。只有必要地形与建筑投影；光源和投影物不变时复用阴影图，编辑或时段变化时标记更新。
4. 地形以坡度、高度和少量纹理区分岩石、植被、河滩；连续地表使用合理平滑法线，岩壁可保留硬边。远景不加载近景贴图。
5. 高档画质才启用轻量 AO 和局部 Bloom；Bloom 限定水流提示与选中标记，维持标签可读性。不默认用景深模糊可点击区域。
6. 后处理使用明确的 RenderPass/效果/OutputPass 顺序；同步尺寸、DPR、抗锯齿方案及资源释放。不能假设默认 framebuffer 抗锯齿会自动覆盖离屏后处理。

### 3.3 地标模型

- 第一批选择 2–3 个有辨识度的文化地标，使用有许可的本地或用户资产。统一 glTF/GLB、单位、原点、朝向、材质与落地锚点；标清实景模型或示意复原。
- 省域总览显示简化符号，城市近景才加载地标。树木、石块等重复资产实例化；编辑时保留稳定业务 ID 与 instanceId 的映射。
- 模型视测试结果选用 Draco 或 Meshopt，纹理可用 KTX2/Basis；衡量解码时间和解码器下载成本。单纯减小 GLB 下载体积不等于减少 GPU 内存或 draw calls。
- 大型近景纹理按需加载。新增 GLB/KTX2 不在现有图片/视频 manifest 的 glob 范围内，应走专用模型资产注册表和统一公开资源地址配置。

## 4. 相机与选择交互

### 4.1 相机唯一控制权

相机状态建议为 `overview / guided / manual / editing`。所有写入经过同一调度器：手动操作与编辑优先；新飞行取消旧飞行；滚动推镜仅在 guided 状态生效。

- 引擎 `init()` 返回可等待的就绪结果，场景与容器尺寸可用后才初始化 ScrollTrigger；取消用固定延迟猜测就绪。
- 飞行使用统一帧循环里的经过时间，建议 600–900ms 缓入缓出，同时插值位置和观察目标；路径考虑地形净空。新选择、用户拖动、Esc、卸载均能取消。
- OrbitControls 保留阻尼，显式设置鼠标旋转/缩放/平移；启用适合地图的 `zoomToCursor`，限制 target 平移范围。缩放、旋转、平移速度按场景尺度校准。
- 桌面提供左键旋转、右键或 Shift+拖动平移、滚轮缩放；触屏默认保留页面单指滚动，点击“操作沙盘”进入明确手势模式，再启用单指旋转和双指缩放/平移。不能把默认双指缩放/平移文案写成双指旋转。
- 提供键盘可达的视角按钮；箭头等快捷键仅在沙盘获得焦点且非输入框时生效。减少动态效果时跳转至终点或使用极短过渡。

### 4.2 选择、悬停与标签

- 在 pointerup 判断点击：主按钮、相同指针、移动量低于阈值（初值 6 CSS px）、非多指/绘制/拖动过程。pointercancel 清空手势。
- 若保留双击导航，必须是同一稳定对象 ID、邻近位置和时间窗口；不同城市连续点击不能触发导航。卡片“进入城市”保留为显式入口。
- hover 与 selected 独立：悬停轻提示，选中持续高亮/底座环，侧栏、标签和对象同步；空白和 Esc 可取消。
- 只对可交互对象/简化命中代理拾取；合并 pointermove 至每帧最多一次。密集地形再按实测决定是否引入 BVH。
- 标签补齐前后裁剪面、XY 视口、遮挡及重叠检查；优先显示选中城市与主要城市。复用向量，按相机变化更新，或最多 15–30Hz，不逐帧替换整组 Vue 对象。

## 5. 拖拽布置与实时编辑

### 5.1 对象布置和建筑参数

- 每个对象具有稳定 ID、assetId、经纬锚点或局部坐标、旋转、正数尺度和允许编辑的参数；Three Object3D 不直接放入深层 Vue 响应状态。
- 素材拖入时显示半透明预览，通过地表 raycast 求落点；支持地表/网格吸附、角度吸附、越界与碰撞提示。
- TransformControls 负责平移/旋转/缩放；拖动开始暂停 OrbitControls，结束或取消必定恢复。Esc 恢复拖动前状态。
- 第一阶段建筑支持位置、朝向、尺度、可选材质；层数/屋顶等结构编辑限于专门的参数化模型，不能承诺任意导入 GLB 都支持。
- 移动预览可逐帧更新，松手仅提交一条撤销命令。清空用户草稿需明确确认，不修改公开文化实体或真实底图。

### 5.2 地形笔刷

- 高度场是渲染、拾取、建筑落地与编辑的统一数据源；提供半径、强度、软边衰减及抬升/压低/平滑/定高模式。
- 使用时间/行程归一化，避免同一笔在不同刷新率下改变不同高度。软边可使用下列数学形式（设计公式）：

  `heightDelta = direction × strength × deltaTime × (1 − smoothstep(0, radius, distance))`

- 只修改笔刷影响的网格块，更新 GPU 属性范围、法线和包围体；平滑读取修改前邻域，避免遍历顺序影响结果。
- 一笔记录受影响顶点的前后值供撤销；笔刷预览可低精度，松手补齐精度。密集计算迁 Web Worker，使用版本号丢弃过期结果。
- 地形变化后更新建筑落地高度；河道设置约束区，第一期禁止破坏河岸/水位，避免引入未经验证的水文模拟。

### 5.3 草稿与撤销

- 建议 IndexedDB 保存本地草稿，可导入/导出 JSON；包含 `schemaVersion`、底图/高程版本、坐标投影参数、对象记录、地形差量、环境配置。大体积高度数组不塞 localStorage。
- 导入校验有限数值、坐标边界、尺度范围、对象数量和 assetId 白名单；缺失资产显示占位及说明，禁止静默丢失。
- 100 次撤销/重做后状态应一致；地形笔画和对象拖动均以一次完整操作为事务。
- 首版用户场景独立于文化内容库；若后续需要分享/云端保存，另立受鉴权的草稿接口，不将用户地形修改复用到已发布文献/景点 CRUD。

## 6. 动态效果与性能分档

先修正城市光圈的具名引用，将所有动画统一为秒级 deltaTime，并在恢复可见时重置/限制过大的 delta，避免瞬移。晴、薄雾、细雨作为统一环境预设，联动太阳强度、雾色、风向、水面和近相机粒子；过渡建议 1–2 秒。

雨、雾、漂浮尘光采用固定预算的 Points/实例化或 Shader，避免每粒子一个 Object3D。透明层数、覆盖面积与阴影次数均计入成本。先实现可开关的薄雾与细雨，再评估额外特效。

| 建议档位 | 渲染比例/DPR 上限 | 阴影 | 动态与后处理 | 建议目标 |
|---|---|---|---|---|
| 省电 | DPR 1，可继续降低内部渲染比例 | 关闭实时阴影或 1024² 单灯 | 无 AO/Bloom；粒子明显减少 | 中档手机约 30fps |
| 均衡 | DPR 1.5 | 1024²–2048² 单灯，按变化更新 | 轻雾、水面、少量天气 | 1080p 桌面约 60fps |
| 精细 | DPR 2 | 2048² 单灯 | 近景地标、半分辨率 AO、局部 Bloom | 以实测帧预算决定是否维持 |

以上为起始配置，不代表当前性能或所有设备承诺。质量系统基于滑动窗口帧耗时，持续超预算才降档，稳定较长时间才升档，设置冷却避免反复跳动；用户可固定档位。不能仅凭 CPU 核数推断 GPU 能力。

- IntersectionObserver + Page Visibility 管理暂停；离开沙盘/后台时停止渲染及天气更新。无动态且阻尼已停止时按需绘制，交互或状态改变时恢复。
- 保留 Three/ECharts/G6 独立分包。场景内按视角加载近景，纹理/几何/材质共享；地标和编辑器可延迟加载。
- 统一释放 RAF、相机任务、事件、ResizeObserver、Controls、纹理、PMREM、render target、后处理 pass 和 Worker。共享资源按所有权释放。
- 初始化使用 generation token/AbortController，卸载后不能因 GeoJSON/模型晚到重建场景。处理 WebGL context lost，提供恢复入口与普通城市列表入口。
- reduced-motion 覆盖自动飞行、河流、节点、天气及滚动推镜；质量选项与无障碍选项独立，低配置不等于减少动态效果偏好。

## 8. 验收方法

### 行为与回归

- 单元测试新增建议：`display-v2/tests/sandboxGesture.test.js`、`sandboxCamera.test.js`、`sandboxTerrain.test.js`、`sandboxDraft.test.js`、`sandboxLifecycle.test.js`。测试真实逻辑，避免仅断言源码包含某字符串。
- 手势：从节点起手旋转不打开侧栏；A/B 快速连点不导航；多指结束不产生额外 click；pointercancel 清理。
- 相机：模拟 30/60/120Hz 的相同经过时间，位置一致；连续点击十次只保留最后目标；手动接管后不回弹；滚动不覆盖手动视角。
- 地形：笔刷越界不写非法值，跨块边缘连续，平滑不依赖遍历顺序，撤销恢复受影响高度与建筑锚点。
- 生命周期：延迟 GeoJSON/模型在卸载后返回不重建；重复进入/离开 20 次，无重复 Canvas/事件/RAF，资源计数不持续增长。
- 浏览器验证使用真实鼠标/触屏/键盘；设计预览仅辅助固定内容截图，最终仍覆盖真实 API 及错误状态。WebGL/视觉不能由 Node 测试替代。

### 性能与视觉

- 记录设备、浏览器、CSS 尺寸、实际渲染分辨率、DPR、画质、网络、对象数和粒子数。建议覆盖 M1/8GB 级笔记本、Windows 核显笔记本、中档 Android 与 iPhone Safari，按实际可用设备记录，不声称全覆盖。
- 每组预热 30 秒，采集至少 60 秒旋转/缩放/选中/天气及编辑操作，重复三轮。输出中位数、P95 帧间隔、卡顿次数、draw calls、triangles、纹理/几何计数；rAF 间隔不是独立 GPU 耗时。
- 建议桌面均衡档 P95 帧间隔不高于约 20ms，移动省电档不高于约 35ms；本地选中反馈不超过 100ms，不含远端详情网络耗时。超预算优先减后处理、分辨率和透明覆盖。
- 冷缓存首次加载另测：在固定 10Mbps/80ms RTT 条件下，建议 3 秒内可操作基础场景，地标分批补齐；最终门槛结合基线和素材体积确认。
- 固定视角截图检查水面穿插、阴影条纹、边缘锯齿、标签遮挡、纸面曝光；连续录像检查切城、取消动画、拖动和天气切换。截图漂亮不代表操作流畅。

## 9. 官方技术依据

- [OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)：阻尼、缩放到光标、鼠标/触屏映射与控制事件；实际实施以锁文件版本 API 为准。
- [TransformControls](https://threejs.org/docs/pages/TransformControls.html)：对象平移、旋转、缩放和吸附。
- [Color Management](https://threejs.org/manual/pages/color-management.html)：颜色输入、线性计算、输出转换与后处理。
- [Shadows](https://threejs.org/manual/pages/shadows.html)：投影光源成本、阴影视锥、静态替代方案。
- [GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html) / [KTX2Loader](https://threejs.org/docs/pages/KTX2Loader.html)：模型、压缩纹理及能力检测。
- [InstancedMesh](https://threejs.org/docs/pages/InstancedMesh.html)：重复几何/材质对象的实例化与包围体更新。
- [BufferAttribute](https://threejs.org/docs/pages/BufferAttribute.html)：顶点属性更新与局部更新范围。
- [How to dispose of Objects](https://threejs.org/manual/pages/how-to-dispose-of-objects.html)：几何、材质、纹理与渲染目标的显式释放。
