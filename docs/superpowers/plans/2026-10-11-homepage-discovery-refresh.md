# Homepage Discovery Refresh Implementation Plan

**Goal:** 优化用户截图里的首页下半部，让体验、九城与诗意入口有可辨认的图像和清楚的操作层次。

**Architecture:** 保留 MapView 上半部、九城胜迹、全部路由和 atlasLink 预览规则；仅改三个底部区域的模板/CSS与装饰图片。无后端、数据审核或模型调用变化。

**Tech Stack:** Vue3、现有 CSS、水墨 WebP、内置 image_gen、Sites。

用户已在本会话授权视觉方向与实施，此次按截图限定范围。对比了只调整间距、增加场景图册和整页重做：采用图册，改善信息辨识，保留已有品牌及功能。复用已有隔离工作区，分支 codex/homepage-discovery-refresh；顺序独立执行，不要求委派。
