# 三维沙盘实施与验收记录

## 已交付

- 将渲染、示意地形、场景编辑、草稿存储拆成独立模块；保留 `/river-sandbox`、九城资料和设计预览入口。
- PBR 材质、柔和方向光、缓存阴影、精确行政轮廓及孔洞、河道流动粒子、晴日/薄雾/细雨。河道来自仓库已有 Natural Earth 提取数据；地形与亭树石为程序化示意，页面明确标注非测绘资料。
- 阻尼旋转、缩放和平移、三种视角、城市飞行与手势中断、点击与拖动区分、遮挡拾取、标签避让、九城下拉入口。
- 亭树石放置/拖拽/旋转/缩放/删除；抬升、降低、平滑、平整地形；保护河道；100 步撤销重做。
- IndexedDB 本地草稿、JSON 导入导出与边界校验、可撤销重置。不写入文化实体 API。
- 三档画质、关闭动态效果、后台暂停、资源释放、异步加载取消与 WebGL 恢复。移动端显式开启操作，编辑时自动开启；窄屏调整相机视场。

## 验证证据

- 专项测试 16 项通过，覆盖手势、飞行、草稿校验、撤销历史、笔刷、几何孔洞、异步生命周期和 UI 错误反馈。
- 仓库全量门禁首次停在 Docker 不可用；启动已有 Docker 后，独立续跑后端 integration/quality 成功（192 单元 + 7 MySQL 集成）。依赖扫描、仓库契约、三前端构建与五页无障碍关卡已通过。
- display-v2 覆盖率采样：行 67.58%，分支 84.81%，函数 84.23%。最后改动另行复跑全量前端测试和构建。
- 真实浏览器操作验证：放置、拖拽、地形笔刷、撤销重做、保存、刷新后恢复、城市选择和天气画质切换。沙盘页 axe WCAG A/AA 无违规；390px 移动仿真无横向溢出，编辑触控切换正常。
- 桌面开发浏览器精细画质+细雨采样60秒：1748帧，平均约29.13 FPS，帧间隔P50 33.3ms、P95 34.4ms。此为单环境 RAF 采样，含交互与无障碍扫描，不能外推真实手机、GPU耗时或全设备60 FPS。
- 浏览器主要验收使用 `?preview=inkwash`，不代表真实后端文化内容验收。截图保存在忽略目录 `.local/sandbox-final.png` 和 `.local/sandbox-mobile.png`。

## 后续边界
