# 素材生成提示词规范 v2 · 版式锚定（2026-10-09）

> 起因：P2 批次 31 张中有若干张出现**版式偏差**——题名被放大成「标题级」、或从右上角掉到画面中部。
> 根因：v1 提示词只写了「画面右侧竖排题写「X」三字」，**没有约束位置、尺寸、比例**，模型自由发挥。
> 本规范把「位置 / 尺寸 / 比例 / 内容」全部写成**显式条款 + 禁止条款**，并给出参考图锚定法。

## 二、提示词模板 v2（诗人水墨画像）

```
中国水墨人物画，工笔与写意结合，3:4 竖幅人物像。

【人物】{朝代}{身份}，{服饰}，{姿态}，{神态}；
半身像，居于画面中央偏左，头顶位于画面高度约 25% 处，身体延伸出画面下缘。

【背景】以淡墨点染{背景意象}，笔触写意，大面积留白。

【题名（位置/尺寸/比例必须严格如下，不得改动）】
画面右上角竖排题写「{姓名}」，共{2|3}字；
题名紧贴右上角，其所在竖向条带位于画面宽度 88%–98% 之间，
首字上缘距画面顶边约 5% 画面高；
单字高度约为画面高度的 4.5%（即约为人物头部高度的三分之一），
{2|3}字连排总高不超过画面高度的 15%；
题名为「小字题签」，**不得放大为标题级，不得下移至画面中部**。

【题款】题名正下方紧接两列小字竖写，单字高约为题名的一半。

【印章】题款末尾钤两方朱砂印章，上下排列，每方边长约为画面宽度的 3%。

【风格】仿古绢本设色，宣纸肌理，淡墨晕染，色调灰褐沉静，无现代元素，无水印。

【版式锚定】以上版式（画幅比例、人物位置与占比、题名位置与字号、题款行数、印章数量与位置）
须与参考图 `pu_songling_anime.webp` 完全一致；仅人物相貌、姓名文字与服饰颜色按本节描述重绘，
其余构图元素的位置、尺寸、比例一律不得改动。
```

### 2.1 条款对应关系（改这条为了防这个偏差）

| 条款 | 防的是什么偏差 |
|---|---|
| `3:4 竖幅` | 画幅比例漂移（后端列表网格按 3:4 显示，比例错会被裁切） |
| `头顶位于画面高度约 25%`、`身体延伸出下缘` | 人物缩成小像、上下留白过多 |
| `题名紧贴右上角…88%–98%` | **题名位置下移/左移**（王冕、刘禹锡案例） |
| `单字高度约为画面高度的 4.5%`、`不得放大为标题级` | **题名字号放大**（陆机案例） |
| `题款两列小字`、`单字高约为题名的一半` | 题款缺失或与题名等大 |
| `两方朱砂印章`、`边长约画宽 3%` | 印章缺失、数量错、过大过小 |
| `右侧题名栏保持纸面留白` | 背景树石侵入题名区，导致文字不可读 |
| `除上述外一律不得改动` | 模型「顺手」重排整体版式 |

## 三、图生图锚定（进一步降低偏差）

文字描述对「位置/尺寸」的控制是概率性的。要**强约束版式**，改用图生图：

```jsonc
{
  "prompt": "<上文的模板 v2>",
  "image1": "display-v2/public/images/poets/pu_songling_anime.webp",  // 版式锚定图
  "input_fidelity": "high",        // 高保真，尽量贴着参考图的结构
  "size": "1024x1536",
  "quality": "high"
}
```

- **锚定图选谁**：优先用**同风格族且已验收**的成品，如 `pu_songling_anime.webp`（原基准）
  或 `wang_zhi_huan_anime.webp`（本配方产出）。避免用旧素材（如 `li_qingzhao_anime.webp`，其题名栏左边界 0.830 本身就不达标）。
- **提示词必须显式说明「人物重绘」**，否则模型会直接复用锚定图里的人脸：
  `保持参考图版式完全不变，但人物改绘为：{朝代}{身份}...`
- **风险**：`input_fidelity` 过高时会连参考图的人物一起抄过来。若出现「换名字不换脸」，
  降到 `medium`，或改用文生图 + 模板 v2 的显式条款。

### 3.1 A/B 实测（2026-10-09，用陆机 / 刘禹锡 / 王冕 三例验证）

| 方案 | 题名位置 | 题名字号 | 人物 | 题款内容 | 结论 |
|---|---|---|---|---|---|
| v1 提示词（P2 原版） | ✗ 掉到画面中部 | ✗ 放大 ≈3 倍 | ✓ | ✓ | 原始偏差 |
| v2 文生图（无锚定图） | ✓ 右上角 | ✓ 小字 | ⚠ 偏小、画面偏暗 | ✓ | 可用但人物占比不稳 |
| v2 图生图 + `input_fidelity: high` | ✓✓ 最准 | ✓ 小字 | ✗ **沿用参考图人物面孔/胡须** | ✗ **照搬参考图题款（抄成《聊斋志异》文字）** | 版式最优但**内容误配** |
| **v2 图生图 + `input_fidelity: medium` + 题款文字写死** | ✓✓ | ✓ | ✓ **完全重绘** | ✓ **文字正确** | ✅ **最终配方** |

**最终配方（推荐，P3 起一律使用）**

```
image1  = display-v2/public/images/poets/wang_zhi_huan_anime.webp   # 已验收的版式锚定图
input_fidelity = medium
prompt  = 模板 v2，且必须包含：
          ① 「只沿用版式与画风，人物必须完全重绘（不得沿用参考图的面孔、胡须、服装与服饰颜色）」
          ② 「题款文字固定写「___」，不得使用其它文字，不得照搬参考图的题款内容」
```

**两条血泪教训**
1. **图生图会抄参考图的题款文字**。只写「两列小字题款」时，模型直接把参考图的题款内容搬过来
   （实测输出把蒲松龄的《聊斋志异》题跋抄到了陆机图上）。**题款文字必须逐字写死，并加禁止照搬条款**。
2. **`input_fidelity: high` 会连人脸一起抄**。要「换人不换版式」，必须降到 `medium` 并显式声明人物重绘。

## 五、对已产出素材的处理原则

1. **不动**：构图与参考图一致、仅细节差异的（占多数）。
2. **重生成**：题名被放大成标题级、或题名落到画面中部的。
3. **不回改旧素材**：`li_qingzhao_anime.webp` 等早期素材本身不在规范内，成本不划算，暂不追溯。
4. 重生成一律走**模板 v2 + 最终配方**，并加入并排对比条验收。
