# 泰安城市页高清配图修复

## 原因

旧泰安主图为 345×450，泰山与玉皇顶图为 338×177、345×174。在 1440 CSS 像素宽、DPR 2 的页面中，图像容器分别约 386×461、444×281、572×358，低分辨率素材被放大。主要图片没有 blur 滤镜。

## 修改

- 泰安主图使用新生成的 1024×1536 水墨意象插画，移除图内题字，题款仍由页面排版提供。
- 泰山与玉皇顶复用已审阅的 1536×1024 原稿，WebP 质量 90。
- 三张图片采用版本化 URL，避免旧缓存；保留原素材以便回滚。
- 配图为艺术意象，并非景点建筑或地理布局的精确复原。
- 不改动公开数据、审核状态及 API。

## 验证

- 展示端 214 项测试通过。
- 本地浏览器请求真实 Railway API，无 preview 参数。
- 桌面 1440×1100、DPR 2：三个图像均成功解码，原生尺寸覆盖当前显示所需像素，无横向溢出。
- 手机 390×844、DPR 2：图像成功解码，无横向溢出。
- 原始主图与浏览器截图保留在主工作区 output/imagegen/city-hd/2026-10-11。
