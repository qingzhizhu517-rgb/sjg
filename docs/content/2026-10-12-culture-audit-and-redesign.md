# 齐鲁文化模块梳理结论与改造说明（2026-10-12）

本轮只修改本地。古诗词不在范围内；没有提交、推送、部署或应用数据库迁移。呈现以真实视频、现场照片、作品图集与来源为主，已撤下本轮批量添加的 SVG 示意、配色与拍点小游戏。

## 现有呈现与素材完备情况

当天公开 API 全量44条：节庆14、工艺12、文学10、饮食戏曲8（饮食4、戏曲／曲艺4）。逐条详情均已读取；44条的 imageUrl／imageAnimeUrl 和后端 sources 均为空，没有绑定真实视频、音频或条目交互。正文和详情档案有内容，但“采集来源”等文本字段不等于可点击、可核验的文献关联。

仓库原有牡丹、祭孔、曹州面塑、鲁锦、甏肉5幅文化插画。旧回填限定本地数字ID，线上ID变化后未挂载。本次按**类别＋精确标题**匹配，复用已有插画并注明其性质；优先展示核验后的真实素材。潍坊风筝图与生产库中的孟姜女ID撞号，没有误挂。

## 本地改造结果

- 44条全部补充具名来源：**84条来源关联，81个去重原页**。
- **34条**接入真实影音，共49项素材；其中24条有视频、17条有照片（两类可重叠）。
- **10条**仍无适合页内呈现的核验真媒体，逐项列出缺口。来源已补齐，不用SVG补成“全可视”。
- 视频播放器默认展示，点击播放即可；没有“先点预览才出现视频”的遮罩。支持MP4及HLS，切换／离开释放播放，外站失效保留原页入口和重试。
- 多图可切换，作品图保留自然比例；列表真实图不叠加水墨混合滤镜。所有媒体保留机构署名和原页。
- 工艺以可展开的工序观察索引辅助观看；民间文学提供故事线索、版本和来源提示；戏曲／曲艺用真实节目里的声音与表演，不以无原唱拍点代替唱腔。
