## 五、录入方式

### 方式 A：一键脚本（推荐）
```bash
node scripts/setup-first-learning-task.mjs          # 预演，只打印将要写入的内容
node scripts/setup-first-learning-task.mjs --apply  # 实际写入
```
脚本会依次登录 → 建 4 条来源 → 建 4 条关联 → 建 1 个任务（草稿），**幂等**，可重复运行；
它使用真实返回的来源 ID 生成任务 JSON，因此不受自增 ID 变化影响。

### 方式 B：手工录入
1. 「来源与审核 → 来源文献」逐条新增第二节的 4 条来源，**记下实际生成的 ID**。
2. 切到「实体关联」，按第三节建 4 条关联（sourceDocumentId 用上一步的真实 ID）。
3. 「探究任务 → 新增」，taskCode 填 `jinan-springs-poets-01`，任务 JSON 粘贴
   `docs/content/jinan-first-task.json` 的内容；**若来源 ID 不是 1–4，需同步替换其中的 `sourceIds`**。
4. 保存后点「发布」。若有报错，按第六节逐项排查。
