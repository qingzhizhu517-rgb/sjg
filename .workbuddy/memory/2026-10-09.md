## 提示词规范 v2 · 版式锚定（2026-10-09 追加）

规范文档：`docs/design/2026-10-09-asset-prompt-spec.md`；
模板固化：`scripts/placeholder-assets/prompt_templates.py`。

### 起因：P2 出现版式偏差
对比条（`compare-poet-layout.png`）发现三类偏差：
- **题名字号放大 ≈3 倍**（陆机：题名笔画块 x 宽 0.215 vs 参考图 0.076）
- **题名从右上角掉到画面中部**（王冕、刘禹锡）
- 根因：v1 提示词只写「画面右侧竖排题写「X」三字」，**没有位置/尺寸/比例约束**。

### 参考图实测真值（蒲松龄 / 王之涣 两图一致）
画幅 0.750（3:4）；题名紧贴**右上角**、笔画块 x∈[0.89,0.97]（占画宽 7–8%）、首字上缘 y≈0.05；
**单字高 ≈ 画高 4.5%**、三字总高 ≤ 15%；题款两列小字（单字高约为题名一半）；两方朱砂印。

### A/B 实测结论（重要，后续必守）
| 方案 | 版式 | 内容 |
|---|---|---|
| v1 | ✗ 题名放大/下移 | ✓ |
| v2 文生图 | ✓ | ✓ 但人物偏小、画面暗 |
| v2 图生图 + `input_fidelity: high` | ✓✓ 最准 | ✗ **抄参考图人脸 + 抄参考图题款文字（把蒲松龄《聊斋志异》题跋抄到陆机上）** |
| **v2 图生图 + `input_fidelity: medium` + 题款写死** | ✓✓ | ✓ **最终配方** |

**两条血泪教训**：
1. **图生图会抄参考图的题款文字** → 题款必须逐字写死 + 加「不得照搬参考图题款内容」。
2. **`input_fidelity: high` 会抄人脸** → 要「换人不换版式」必须 `medium` + 显式声明「人物完全重绘」。

### ⚠️ 方法论教训：不要再用像素启发式自动判定题名栏
