## 一、3D 沙盘写实化改造（分支 `feat-3d-sandbox-realism`，提交 8e87e8c）

用户需求：「新建分支优化 3D 沙盘，模拟真实城市和黄河景观，包括可交互点击的九大城市」。
确认方向：写实山水基调 + 程序化建筑群 + 仅沙盘内点击联动（不做外部城市清单条、不做沿河巡游）。

### 改动
- 新增 `display-v2/src/utils/sandboxTerrain.js`（679 行）：经纬投影、九城坐标、黄河实测走向、
  确定性值噪声、高度场、分层设色、解析法线、多边形裁切与网格生成、黄河带状网格、河口三角洲。
- 新增 `display-v2/src/utils/sandboxBuildings.js`（97 行）：mulberry32 PRNG + 按城市等级生成建筑布局。
- 重写 `display-v2/src/composables/useThreeSandbox.js`（1467 行 diff）。
- `display-v2/src/views/MapView.vue`：接入悬停联动，去掉逐城色值内联样式，更新提示文案。
- 新增 `tests/sandboxTerrain.test.js`、`tests/sandboxBuildings.test.js`（共 34 个用例）。

### 关键实现决策
- 地形用「网格 + 轮廓裁切」：格点在轮廓内用高度场，越界格点吸附到边界，
  每格点独立顶点（不共享索引），法线走解析梯度而非 computeVertexNormals。
- 山体用「窄主峰 + 宽山裙」两级剖面。单一宽山体会在 30× 垂直夸张下退化成光滑圆锥甚至针尖；
  半径过大又会把泰安市区整个抬到半山腰（实际泰安与玉皇顶高差近 90%）。
- 黄河改为带状网格：滩区整体下沉 + 河槽内抬出两岸堤防 = 「地上悬河」断面；
  泥沙流动用程序化 CanvasTexture 滚动 offset；入海口把滩面与水面压到海平面。
- 建筑群单个 InstancedMesh（1004 个实例，一次 draw call），陡坡（法线 y < 0.5）不建。
- 拾取从「全场景射线」收窄为 9 个不参与渲染的代理圆柱体，射线只测这 9 个。

### 实测踩坑（都是无头截图才发现的）
1. **地形三角形绕序朝下** → 整片陆地被背面剔除，只剩深色底板。
   正确绕序是 a→c→b / a→d→c（右手系下法线朝 +Y）。已加回归测试。
2. **网格间距 0.2，山峰解析高程高于插值网面** → 建筑与碑刻悬空。
   新增 `terrainGroundY()`（取中心与 8 点环的最小值）贴合地表。已加回归测试。
3. 地形构建耗时 405ms；法线原先每个格点算 6 次，改为按格点缓存后降到 **100ms**。
4. 噪声频率上限受网格间距约束：波长低于 0.4 单位会走样，故 fbm 频率最高只取到 3.3。

### 验证
`node --test tests/*.test.js` → 99 passed / 0 failed（含既有 65 个）；`vite build` 通过。

## 二、数据大屏（sjg-datav）现状排查（分支 `feat-datav-overhaul`）

用户反馈「对目前效果并不满意，有什么布局或展示建议」。先在**数据桩 + 无头截图**下渲染出真实版式
（后端 8080 未运行，大屏无 mock 降级，直连会全屏 0/—）。

### 确认的 5 处版式硬伤
1. `NumberAnimation.tsx` 残留旧 AI 紫渐变 `#667eea→#764ba2` + `background-clip:text`，
   覆盖掉 `--dv-gold-light`，右栏三个核心指标渲染成紫蓝色。
2. `SentimentCloud` 默认 `width=400, height=300` 写死，卡片内可用宽度仅约 324px → 右侧与底部被裁。
3. `ShanheMapChart` 的 `geo.layoutSize: '96%'` 没吃到容器宽度，地图只占中央栏约四成宽。
4. `RightPanel` 四张卡**都没有 `flex` 声明**（`LeftPanel` 的卡有 `flex:1`），
   总内容约 1079px > 可用 908px，被 flex-shrink 按比例压扁：诗人榜从 8 行裁到 5 行，
   词云卡被压到约 315px 而内容需 374px。**这是右栏塌掉的根因。**
5. `LeftPanel` 第二张卡 `align-content:center` + 内容仅 158px 而卡高 470px → 上下各留白约 150px。

  Windows 回落 SimSun，500/700 字重全部失效。

- **数据只用一半**：`events` / `dynasties` / `timeline` 三个已有公开接口大屏零消费；朝代名还是硬编码 mapping。
- **死代码**：`src/pages/DataV/map/*`（5 文件 214 行）、`test.tsx`~`test8.tsx`（8 文件）、
  `components/TimelineChart.tsx`、`pages/DataV/stores/index.ts` 全部零引用，但都被 `tsc -b` 检查。
  ⚠️ **CLAUDE.md 称 `map/` 目录不存在，是错的，它存在且是死代码。**

## 二·续、数据大屏改造实施结果（提交 6a33b74）

用户确认方向：三栏+底部时间轴 / ECharts 增强地图 / 交互只做「点九城联动 + 时间轴朝代联动」（不要悬停浮层）/
顺带全做（清死代码、引入中文字体、补三态、图表主题常量化）。

### 版式
三栏 340 / 1fr / 340 + 底部 148 通栏时间轴；顶栏 92。
左右各三张等高卡：左＝九城榜 / 五脉文华 / 诗情词意，右＝数据概览(2×2) / 传世诗人榜(8行) / 朝代分布(环形)。
**卡片一律显式 flex（`flex: N 1 0`）**——这是右栏曾经塌掉的根因。

### 地图缩放根因（重要，别再踩）
读 `node_modules/echarts/lib/coord/geo/geoCreator.js` 确认：
```js
aspect = rect.width / rect.height * aspectScale
size = parsePercent(sizeOption, Math.min(refContainer.width, refContainer.height))
if (aspect > 1) { viewRect.width = size; viewRect.height = size / aspect }
```
即 **百分比 layoutSize 相对容器短边，且 size 成为地图长边**。
原先写 `'96%'`，容器 1176×794 → 只吃到 794 → 地图宽 762，白白浪费 400px 横向空间。
现改为按长边显式计算绝对像素：`fitted = min(boxW, boxH * GEO_ASPECT)`，GEO_ASPECT 由
GeoJSON 实际经纬跨度 × `aspectScale(0.805)` 现算，不硬编码。

### 其它
- 真实黄河河道（19 点，与 display-v2 的 `YELLOW_RIVER_GEO` 同源）替换九城直连假线。
- 新增 `useDashboardData`：城市筛选走「诗 → poem.spotId → spot.region」归属（poets 表无 region 字段）；
  朝代筛选走 dynastyId。筛选状态支持 `?region=&dynasty=` 深链。
- 起用了此前零消费的 `/dynasties` 与 `/events`。**刻意不用 `/timeline`**——它每朝代 4 次查询且不分页，
  而这三份数据大屏本来就要拉。
- 新增 `theme/chartTheme.ts`（从 `:root` 读色值，ECharts 读不到 CSS 变量）、
  `theme/echartsSetup.ts`（按需注册集中一处）、`components/PanelKit.tsx`（Card + 三态）。
- 字体：Noto Serif SC 用 `pyftsubset` 按「源码 + 后端种子 SQL」抽取的 2097 字子集化 → 354KB 本地托管。
  子集脚本思路见技能 `spa-stub-visual-review` 的姊妹技能或本节记录；字重只用 400（CJK 合成粗体会糊）。

### 验证

## 三、环境限制（重要，两个分支都要看）

### git 分支
- **无法创建 `feat/xxx` 形式的引用**：报 `cannot lock ref`，`.git/refs/heads/` 下新建子目录不持久。
  只能用扁平名：`feat-3d-sandbox-realism`、`feat-datav-overhaul`。
- 受限时 `git checkout -b` 会**静默切到未出生分支**（退出码 0 但无提交），
  随后 `git status` 把 index 全部文件显示为 `A`。判别：`git rev-parse HEAD` 报 `Not a valid object name`。
  恢复：`git symbolic-ref HEAD refs/heads/master`。
- 提交后 git 后台 `geometric-repack` 会报 `renaming pack ... File exists`，
  用 `git -c gc.auto=0 -c maintenance.auto=false <cmd>` 规避；不影响提交对象。

### ⚠️ checkout 丢文件事故
`git checkout master` 时工作区 **96 个文件被静默删除**（`display-v2/src/{api,assets,config,router,styles,themes,utils}`
等整目录消失），但 index 与 HEAD 完好，`git restore --source=HEAD --worktree .` 全部无损还原。
**教训：本环境每次切分支后必须立刻 `git status --short` 复核，见到 `D` 马上 restore。**

### 本机服务
- 后端 8080 未运行时会走系统代理返回 502；`curl` 访问 `localhost` 会命中代理，
  要用 `127.0.0.1` 且加 `--noproxy '*'`。
- vite 默认只绑 `localhost`，脚本里要显式 `--host 127.0.0.1` 才能用 IP 访问。
