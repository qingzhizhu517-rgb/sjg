## 环境笔记（本次踩到的）

### 后端构建：必须用 JDK 17，且用 IDEA 内置 Maven
```bash
export JAVA_HOME="D:\\app\\jdk\\17"          # 见下：JBR 是 Java 25，Lombok 不工作
export PATH="$JAVA_HOME/bin:<PortableGit>/mingw64/bin:<PortableGit>/usr/bin:/c/Windows/System32"
cd backend
"/d/app/idea/IntelliJ IDEA 2026.1.2/plugins/maven/lib/maven3/bin/mvn.cmd" -o test
```
- `mvn` 不在 PATH，`mvnw` 不存在；IDEA 内置 Maven 可用（`mvn.cmd`，不是 `mvn` 脚本——
  bash 脚本在 Git Bash 下会报 `找不到主类 org.codehaus.plexus.classworlds.launcher.Launcher`）。
- **不要用 IDEA 的 JBR**（`/d/app/idea/IntelliJ IDEA 2026.1.2/jbr` 是 Java 25）：
  Lombok 注解处理不生效，会在**未改动的文件**里报一堆「找不到符号 getXxx()」，
  极易误判成自己改坏了。本机可用 JDK：`/d/app/jdk/{11,17,21}`。
- `.m2/repository` 已存在，加 `-o` 离线跑即可。

### 其它

## 数据库素材缺口审计（同日）

### 数据库连接方式
- 本机 MySQL 在跑，**客户端在 `/d/app/mysql/install/bin/mysql.exe`**（不在 PATH）。
- 连接参数取自环境变量：`MYSQL_HOST` / `MYSQL_PORT` / `MYSQL_USER` / `MYSQL_PASSWORD`
  （`application.yml` 读的是 `SPRING_DATASOURCE_*` / `DB_PASSWORD`，同一套库）。
- ⚠️ **有效库是 `sjg01`，不是 `sjg`**。两者并存：`sjg` 是近乎空的旧测试库
  （诗 8 / 诗人 6 / 景点 10），`sjg01` 才是生产副本
  （诗 203 / 诗人 129 / 景点 71 / 文化条目 63）。
- 具体实例数别信 `information_schema.TABLE_ROWS`（InnoDB 估算值），要用 `COUNT(*)`。

### 媒体字段的两种存储形态（排查时容易漏）
- **OSS 外链**：存成 **JSON 数组字符串**，如
  `["https://shandong-lit-landscape.oss-cn-beijing.aliyuncs.com/spots/xx.jpg", ...]`
- **本地资产**：存相对路径，如 `/images/spots/baotu_spring.jpg`（落在 `display-v2/public/`）
- 因此「字段非空」不等于「素材存在」：`[]` 空数组等同于缺失，必须解析后判断。

### 审计结论（详见 `output/media-gaps.md` + `media-gaps.csv`）
- **全空字段**：`poem.audio_url`（203/203 全缺）、`cultural_item.image_url`（63/63 全缺）
- 严重缺口：`poet.avatar_anime_url` 缺 121/129、`poet.avatar_url` 缺 103/129
- 选择性缺口：`poem.video_url` 缺 168/203、`scenic_spot.video_url` 缺 56/71
- 数据库引用的 23 个本地路径**磁盘上全部存在**，无失效链接
- 特例：景点 #70 青岛·崂山 三个媒体字段全是 `[]`，素材从未上传

### ⚠️ 本机无法核实 OSS 素材
阿里云 OSS 域名在本机被拦：DNS 返回 fake-ip（`198.18.0.x`），
即使经 Cloudflare DoH 拿到真实 IP（`59.110.190.22`）再 `--resolve` 直连也是 SSL 失败。
连无头浏览器（正常进程）加载 186 条 OSS 链接也是 **0 成功 / 186 失败**。
这与素材是否真实存在无关，**属于网络策略**，不要把「加载失败」当成「素材缺失」上报。
（对照：`cdn.jsdelivr.net` 同样解析到 `198.18.0.13` 却能正常访问，说明是代理放行名单问题。）
