# 山河有迹 · 文脉有声 — 清晰叙事版

## 用户反馈后的状态

用户认为本重制版没有带来视觉提升；该意见已接受。本版不应称为原片的视觉优化稿。2026-10-03另外修复了产品演示的滚动卡顿，输出 `山河有迹·文脉有声-滚动修复版.mp4`，保留此前成片供对照。它沿用本重制版构图，只修正运动缺陷。

当前 `film.js` 使用 `capture-smooth/manifest.json`：网页滚动每帧在真实页面上设置位置，等待绘制完成再截图，按30fps编排。它是逐帧重建的真实界面演示，不是实时录屏；静止阅读时允许复用同一张截图。没有采用光流插帧，没有把文字变形来补帧。以下对10fps和58帧的说明为此前交付版本的历史记录，当前渲染不再引用那些素材。

重新制作时，先运行 `node promo-film/v2/capture-smooth.mjs`（网站须运行于5175）。用 `node promo-film/v2/motion-check.mjs promo-film/v2/capture-smooth/manifest.json` 检查滚动采样，再按下面的渲染、混音、验证步骤输出。`check-video-motion.py` 比较最终视频滚动区域与旧版的相邻帧变化，结果见 `quality/encoded-motion.json`；它补上了原有规格检查遗漏的运动连续性检查。

第二版围绕“从一首诗找到一处山河”组织。片长77.7秒，1920×1080、30fps，H.264/AAC。成片在上一级 dist 目录，文件名为 `山河有迹·文脉有声-清晰叙事版.mp4`。第一版成片保留。

## 本版做了什么

- 取消旧风景插画的独立大图镜头，用新绘制的地理图形、诗句、关系线和重新采集的网站界面组织画面。
- 使用米白、墨绿、朱红的固定配色及统一字体。文字没有水纹变形、色散和颗粒叠加。
- 用《望岳》串起检索、原文、杜甫资料和研学入口。产品从17.5秒出现。
- 九市行政区域、黄河河道和城市中心分别绘制；城市之间的连线不冒充河道。地图中标注“区域示意”。
- 重新编排合成旁白、短句字幕及配乐音量，保留阅读停顿。

## 边界与来源

地图河道来自 Natural Earth 1:1000万数据，210个连续原始节点。行政边界使用本地山东16市数据，与DataV数据一致，但未附CRS声明。河道采用WGS84；因此地图仅供区域文化示意，不用于导航或精确测量，不宣称反映当前精确入海口。具体来源、处理和检查见 `data/sources.md`、`data/validation.json`。

界面素材均在本次重新采集，来自实际运行网站的《望岳》检索、原文与注解、杜甫资料和研学入口。它们是按10fps播放的交互截图序列，实际采样间隔并不完全均匀；后期做了等比例缩放和裁剪。没有伪造搜索结果、光标动作、任务数据或注解。网站本身现有的图片仍可能出现在真实界面内部；没有把它们重新用作独立景观素材。采集记录见 `capture/README.md` 和清单。

杜甫段另外采集了2880×1800的高清素材，实际使用连续58帧，已包含滚动和展开作品的动作，其后停留在最后一帧。原计划80帧的采集中断后，没有补造帧或声称全部采集完成；可用范围与尺寸校验见 `capture/poet-hires/manifest.json`。

网站公开数据存在同名重复作品，《望岳》的独立来源数组为空，研学也没有可核验的已发布任务。因此本片不宣传作品总量、所有内容均可追溯、已完成研学任务等。展示注解不等于对注解所写版本信息完成学术核验。

旁白使用本地 macOS Tingting 合成语音；不是录音演员或真人配音。配乐沿用第一版独立音轨，并重新做音量与人声避让。本版没有生成新的AI山水图，没有调用arkcli或其他生图服务。

## 如何编辑

- `prepare.mjs`：旁白文案、场景最低时长、音频与时间轴。
- `film.js`：九个场景的构图、动画、地图和界面裁剪。
- `draw.js`：配色、字体、绘图基础和短句字幕。
- `data/map.json`：地图与九市点位。
- `capture/`：可重复使用的真实截图序列及采集记录。
- `render.mjs`：渲染关键帧或整片无声视频。
- `mix.mjs`：混音和导出。
- `verify.mjs`：规格、完整解码、黑帧、音量、旁白时长及逐秒截图检查。

在仓库根目录依次运行：

```sh
node promo-film/v2/prepare.mjs
node promo-film/v2/render.mjs --stills
node promo-film/v2/render.mjs
node promo-film/v2/mix.mjs
node promo-film/v2/verify.mjs
```

只修改中间某个镜头时，可以运行 `node promo-film/v2/render.mjs --scene poet`，再运行 `node promo-film/v2/replace-scene.mjs poet`，之后重新混音导出和校验。局部替换保留整片原有帧数，替换前的无声视频自动备份在 `.build`。

需要本机 Node.js、FFmpeg、macOS say 和已有 Chromium。修改旁白时须同步调整 draw.js 的短句字幕。浏览器字体使用 macOS 宋体与苹方；不同机器的字体替代会影响排版。渲染脚本通过 Canvas 输出，页面本身的状态文字不会写进视频。网页预览可运行原有 tools/serve.mjs 并打开 `/promo-film/v2/index.html?play`；网页预览不含混合音轨，审核声音请播放最终MP4。

## 质量记录

`quality/` 保存关键帧、逐秒帧、转场边界帧、渲染记录与最终技术校验。`final-validation.json` 记录最终视频的真实参数，`visual-review.md` 记录人工检查结论。音量技术合格不代表真人配音的自然度，仍建议最终发布前实际试听。
