## 透明融合与清晰度

- 素材以真实 Alpha 透明通道去除原截图纸底，并保留雾气、浅墨和边缘的渐变透明。应在页面暖白底 `#F5F2EB` 上检查合成效果，不要在导出、压缩或格式转换时丢弃透明通道。
- 透明像素中的 RGB 值不等于最终显示颜色。查看文件时应使用支持透明合成的预览工具；将透明图直接铺成白底或忽略 Alpha，可能出现边缘、色块或画面发黑。
- 当前文件的清晰度受原参考截图限制。尤其四张 111–155 px 级人物小像、294 px 宽题字和约 340 px 宽景点画，放大后会显露截图压缩与笔触细节不足。
- 全身立绘与半身小像采用不同展示比例。小像不能通过放大或拉伸变成高精度全身画像；需要更高质量时，应替换为重新绘制或另行生成的高清原画。

## 替换要求

1. 保持文件名和公开路径 `/media/inkwash/atlas/<文件名>.webp`，即可继续被现有页面和预览配置引用。若改名，须同步检查 `src/config/atlasPreview.js`、各页面及首页组件中的引用。
2. 保持对应文件的宽高比、主体位置和外围留白。长幅人物应完整保留头部、衣摆及落脚点；景点画保持横向册页构图；小像维持半身比例。不要用强制拉伸补足容器。
3. 继续保留透明背景及柔和边缘，避免把新的纯白、米色或棋盘格背景烘焙进图片。调色时以暖白页面上的实际合成为准。
4. 高清替换图应按“实际显示尺寸 × 目标设备像素比”准备，而不是简单放大旧文件。例如，显示宽度约 550 px 的主立绘，在 2 倍像素密度屏幕上宜提供约 1100 px 宽、保持原比例的原画。
5. 人物题诗、景点说明及页面标题尽量由页面文字排版。`hero-title.webp` 是目前专门保留的书法题字素材；更换人物主画时不要再次把页面已有题诗画入图片，避免叠字。
6. 替换后检查桌面与 390 px 手机宽度，确认人物没有截头、景点主体未被裁掉、题诗不压住脸部、透明边缘没有白框，同时核对四位人物预览的身份和图片对应关系。

如果后续换成新绘制或新生成的素材，应同步更新本清单的来源、尺寸和处理说明，保留本次参考图派生记录。
