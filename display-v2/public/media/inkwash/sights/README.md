## 来源与加工

- **来源**：2026-10-05 用内置生图工具按 `docs/design/2026-10-02-nine-sights-prompts.jsonl`
  的九条提示词逐张生成。提示词在 2026-10-02 已写好但当时环境没有生图工具，本轮才补生成。
- **原始件**：`output/imagegen/nine-sights/_raw/<slug>-raw.png`（带水印原稿）
  与 `output/imagegen/nine-sights/<slug>.png`（已去水印、1536 × 1024）。
- **去水印**：生成器在右下角压固定水印。已用固定几何遮罩（距右 132px、距下 80px，按图高 /1024 缩放）
  清除，遮罩内以「最平坦纸区」的真实纸纹重建。九张逐一验收无残字、无接缝。
- **边缘羽化**：外侧 6% 平滑羽化为透明。页面底色 `#F5F2EB` 与插画纸底基本同色，
  羽化后不再出现硬切矩形；11% 会明显吃掉边缘笔触，故取 6%。
- **不使用 `mix-blend-mode`**：插画纸底比卡片底色略暖略深，相乘后会形成更明显的暗色矩形，
  与首页主画（近白天空）的结论不同，此处直接按普通图像渲染。

## 放置约定

- 图像外框为 3:2，与 `.atlas-sight__image` 的 `aspect-ratio: 3/2` 一致，`object-fit: cover` 不会裁到主体。
- 卡片实测显示宽 405 CSS px，导出 1024px 宽 → 在 2 倍像素密度屏幕上仍有约 25% 余量。
- 前 3 张（首屏）用 `loading="eager"`，其余用 `lazy`；均带 `width`/`height` 以避免布局抖动。

## 替换要求

1. 保持文件名与路径 `/media/inkwash/sights/<slug>.webp`。
2. 保持 3:2 画幅与主体位置，主体不要贴边——四边需留出可羽化的余量。
3. 保留透明通道与柔和边缘，不要烘焙纯白或米色背景。
4. 替换后跑 `node --test tests/nineSights.test.js`（校验每张图存在且无多余孤儿文件），
   再按桌面 1440 与窄屏 390 两个宽度截图复核。

> 画面为艺术表达，不作真实地理底图或建筑测绘依据。
> 马踏湖一张按提示词要求「前景无人物」，成图舟上有一位极小舟子，属生成偏差，已评估保留。
